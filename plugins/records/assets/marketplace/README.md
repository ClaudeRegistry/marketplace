# Marketplace screen source

This HTML/CSS source renders the three Records Marketplace screens at exactly 1600 × 1000 pixels:

- `?screen=validation`
- `?screen=doctor`
- `?screen=ci`

The visual system follows the MedVertical brand documentation in the `medvertical` website repository. The Records app icon is loaded from the canonical plugin asset one directory above. Screen content is based on the repository's executable fixtures and generated CI output rather than invented product results.

Render in a browser with a 1600 × 1000 viewport and capture the page without browser chrome. Re-export all three images after changing this source so their shared system remains consistent.
